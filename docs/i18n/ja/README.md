# 存在からの物理学 — ドキュメント

存在からの物理学（Physics from Existence, PFE）は、近藤秀和（Kondo Research Institute, 東京）による研究プログラムです。「存在する」とは何かを定式化すると、自由パラメータを一切含まない単一の方程式 $V = -H$ が一意に導かれる、というのがその出発点です。この方程式から導出される数学的構造が標準模型の構造と対応することを示し、標準模型の26個の物理定数が、調整可能なパラメータなしに再現されます。

このページ群は、公開論文リポジトリに付属するものです。論文本体は [`paper1/`](../../../paper1/) に LaTeX・PDF・検証コードとして置かれ、全ての版が Zenodo にアーカイブされています。ドキュメントは、リポジトリに何があるか、数値をどう再現するか、版がどう関係するかを説明します。
