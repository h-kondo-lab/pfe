# 検証

論文の表にある数値の主張は全て、[`paper1/`](../../../../paper1/) の2本のスクリプトから再現できます。導出に実験値は一切入りません。実測値は比較列にだけ現れます。

## 必要なもの

- Python 3
- NumPy 2.0 以上——スクリプトは `numpy.trapezoid` を使うため、NumPy 1.x には存在しません
- SciPy 1.10 以上

```bash
pip install "numpy>=2.0" scipy
```

## 実行

```bash
cd paper1
python physics_from_existence_pure.py
python physics_from_existence_verify.py
```

2本のスクリプトは導出と検証を分けています:

| スクリプト | 内容 |
| --- | --- |
| `physics_from_existence_pure.py` | $V = -H$ だけから物理量を導出します。コード中に実験値は一切現れず、コメントは論文の節に沿って付いているので、導出を単独で読めます。 |
| `physics_from_existence_verify.py` | 同じ導出を実行してから、結果を実験（CODATA 2022、PDG 2026、NuFIT 6.1）と比較します。実験値は別の関数で読み込まれ、比較にだけ使われます——入力には決して使われません。 |

どちらも成功すれば終了コード 0 で終わります。検証スクリプトはバナーに対応する論文の版を表示するので、[現行リリース](../04-releases/README.md) と一致していることを確かめてください。

## 出力の読み方

検証スクリプトは論文の鎖を順にたどります:

1. **方程式と束縛状態。** $V = -H(\sigma(\phi))$ のシュレーディンガー方程式を格子上で解き、3つの束縛状態のエネルギーを最初の連続準位とともに表示するので、個数 $N = 3$ が直接見えます。続いて WKB の個数と、そこから導かれる量 $\varepsilon$ を、独立に認証された区間値と並べて表示します。
2. **導出量。** ゲージ結合定数、Higgs の比、質量比、混合角、ニュートリノ質量を、それぞれ実測値と相対差の隣に表示します。
3. **網羅表。** 最後に、論文の表 1–4 の全行を次の4つのラベルのいずれかで列挙します:

| ラベル | 意味 |
| --- | --- |
| evaluated | このスクリプトが計算し、実験と比較した |
| certified | 区間演算で包囲されている（証明書は別のスクリプトで、本リポジトリには含まれない） |
| comparison-only | 実測値だけを表示。導出は論文 II にある |
| not implemented (Paper II) | 論文 II で導出され、ここでは再計算しない |

*evaluated* か *certified* の印がない行は、再現したとは主張しません。これがリポジトリ単独で検証できる範囲の正直な境界です。

## 精度

格子ソルバーは浮動小数点で動きます。論文の表示桁は、論文に記した高精度評価と区間認証評価によるもので、両者が異なる箇所ではスクリプトが両方を表示します（例えば WKB の個数では、格子値と認証値が表示桁まで一致します）。論文が「全次数」の値を引く箇所では、スクリプトは閉じた形の評価と、それが入る認証区間を表示します。
