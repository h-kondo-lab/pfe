# Releases

## Versioning

- Every version is a Zenodo record under the concept DOI [10.5281/zenodo.19451887](https://doi.org/10.5281/zenodo.19451887), and a git tag of the same name in this repository. The tag's `paper1/` holds exactly the files of that Zenodo record, plus the Japanese edition and figures.
- File names never change between versions; their contents are replaced.
- A **patch** version (v3.2.1, v4.1.1) is errata only: wording, cross-references or table layout, with no change to any numerical value. A **minor** version revises content. A **major** version restructures the paper.
- Published versions are never edited. A correction that becomes necessary after publication is released as the next patch version.
